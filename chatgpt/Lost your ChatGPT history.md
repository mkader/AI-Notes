Lost your @ChatGPTapp history? Steps to recover:
1. In ChatGPT go to Settings→Data controls→Export data
2. Extract the conversations.json file from downloaded export
3. Compress conversations.json using zip or otherwise.
4. Attach conversations.json.zip to a new chatgpt session then prompt it: 

Generate an HTML file with all the links from attached conversation history. Include Title, Update_Time, Default_Model, and Link to the conversation. Sort by Update_Time from recent to old. Support unicode.
