### Workflow patterns overview (4 basic patterns)
  * a sequence of agent (prompt chaining) - the output of an agent in the chain becomes the input of a subsequent agent.
  * loop - invoking the same agent again and again until a given condition is satisfied.
      * This is also called reflection because allow the agent to reflect on its own work and improve it up until a given condition is satisfied
  * parallel - different agent that are independent
  * conditional invocation or routing - to decide which of a set of agent has to be called given a specific condition.

### Supervisor agent pattern (LLM-driven orchestration)
* Agent that can autonomously take decision, decide which agent it wants to invoke and with which argument.
* very simple an architecture - supervisor agent
   * this time I'm not saying invokes A, B and C in a sequence.
   * I'm telling to the supervisor your sub agent are A, B and C
   * it's up to you to decide how and when to invoke them.
