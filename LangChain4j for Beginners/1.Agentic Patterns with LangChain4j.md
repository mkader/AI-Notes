### Workflow patterns overview (4 basic patterns)
  * a sequence of agent (prompt chaining) - the output of an agent in the chain becomes the input of a subsequent agent.
  * loop - invoking the same agent again and again until a given condition is satisfied. This is also called reflection because allow the agent to reflect on its own work and improve it up until a given condition is satisfied
  * parallel - different agent that are independent
  * conditional invocation or routing - to decide which of a set of agent has to be called given a specific condition.
